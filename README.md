# Dionovan Ramadhani — Developer Portfolio

A high-performance, responsive developer portfolio featuring a premium **Gruvbox Dark Retro Terminal** design system. Tailored for showcasing Full-Stack, Web3, and Game Development projects, career progression, and professional expertise.

Built with **Next.js**, **React**, **Tailwind CSS**, and animated with **Framer Motion**.

---

## 🎨 Design Philosophy & Features

- **Gruvbox Color Palette**: Implements the iconic retro Gruvbox dark color scheme (soft contrasts, dark charcoal background, muted greens, yellows, and blues) designed for readability and aesthetic appeal.
- **Hash-Based SPA Routing**: Native-feeling Single Page Application (SPA) experience synced directly to the browser URL hashes (`#home`, `#projects`, `#experience`, `#skills`, `#about`, `#contact`), enabling bookmarks and seamless back/forward browser navigation.
- **Dynamic Project Filtering**: Interactive segmented grid filters for classifying projects into categories (_Web Apps_, _Smart Contracts_, _Games_). Adapts dynamically to a compact grid control on mobile/tablet screens.
- **macOS Solidity Terminal Mockup**: Custom code window component for smart contract projects lacking screenshot previews, displaying syntax-highlighted Solidity scripts alongside a CPU schematic watermark.
- **Intelligent Custom Cursor**: High-fidelity spring-physics custom cursor that transforms upon hovering interactive nodes, automatically fallback-disabling on touch screen devices to prevent UX conflicts.
- **Accessibility First**: Semantic HTML structure (`<header>`, `<main>`, `<nav>`, `<aside>`, `<a>` links) integrated with clean global keyboard focus rings (`focus-visible`) mapped to the Gruvbox design token colors.

## 🛠️ Technology Stack

- **Framework**: Next.js (App Router, Tailwind CSS support)
- **Language**: JavaScript / Node.js
- **Styling**: Tailwind CSS (Shadcn HSL color mappings)
- **Animations**: Framer Motion
- **Icons**: Lucide React & Simple Icons CDN (dynamically colored SVGs)
- **Deployment**: Ready for Vercel / Netlify / Standalone Docker builds
